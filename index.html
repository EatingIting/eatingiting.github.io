About

• 운영 중심의 사고: 로컬 개발 환경과 실제 운영 서버 간의 간극을 줄이기 위해 Docker 기반의 컨테이너 환경을 적극 활용합니다. • 지속 가능한 코드: 기능을 빠르게 만드는 것보다, 서비스가 성장함에 따라 유연하게 대응할 수 있는 객체지향적 설계와 클린 코드를 중요하게 생각합니다. • End-to-End 이해도: 백엔드 로직 설계부터 DB 모델링, 클라우드 환경에서의 배포 자동화까지 전체적인 서비스 흐름을 직접 구축하고 경험하는 데 열정을 가지고 있습니다.

일하는 방식

구조적 설계: 큰 문제를 해결하기 위해 작은 단위(Module)로 나누어 접근하며, 각 기능이 전체 시스템 안에서 명확한 역할과 책임을 갖도록 설계합니다.

문서화와 기록: 트러블슈팅 과정과 기술적 의사결정의 근거를 기록하여 팀의 자산으로 남깁니다. 이는 협업 시 불필요한 커뮤니케이션 비용을 줄이는 핵심이라고 믿습니다.

환경의 표준화: 팀원 누구나 동일한 환경에서 개발할 수 있도록 인프라를 코드화(IaC)하고 자동화하는 과정에 집중합니다.

관심 분야

Architecture: 마이크로서비스 아키텍처(MSA)를 위한 백엔드 설계 및 성능 최적화.

Communication: WebSocket 및 STOMP를 활용한 실시간 데이터 처리와 동기화 문제 해결.

DevOps: Docker 기반 개발/배포 환경 표준화, EC2 배포·운영 경험, Kubernetes 기본 개념 및 사용 흐름 학습.

Security: OAuth2와 JWT를 활용한 안전하고 효율적인 인증/인가 시스템 구현.
